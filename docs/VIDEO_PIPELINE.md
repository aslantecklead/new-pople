# Анализ и монтаж

1. Вставьте текст и нажмите **Выделить ключевые слова**. Ввод сам по себе не отправляет запросов к модели. Проверьте русскую тему и английский запрос; их можно менять.
2. **Найти кадры** использует Яндекс.Картинки для русских тем и Coverr для английских запросов. Модель также формирует до двух английских вариантов той же темы для расширения поиска видео. При ручном редактировании темы эти варианты сбрасываются.
3. Выберите материалы. Кнопка сборки импортирует их на сервер. Локальная модель сопоставляет фразы с названиями и тегами выбранных материалов; исходный текст и его порядок сохраняются. Если подходящего кадра нет, используется текстовая подложка. Это сопоставление по метаданным, не распознавание содержимого видео.
4. Piper `ru_RU-irina-medium` озвучивает смысловые фразы локально. Длительность каждого отрезка измеряется по PCM-аудио и округляется до видеокадра. Фраза целиком отображается в этот интервал; покадрового выделения отдельных слов нет. Фото плавно приближаются, титры голубые с коротким появлением, логотип находится справа сверху.
5. Итог: **1080×1920, 30 fps, H.264/yuv420p, AAC, MP4 faststart**. Просмотр и скачивание доступны на экране результата. Промежуточная раскадровка с текстом, ID кадров и длительностями сохраняется в `media/outputs/<job-id>/timeline.json`.

## Обновление

После `git pull` пересобирайте **оба** сервиса: `docker compose -f docker-compose.server.yml up -d --build api worker`.
Первый build скачивает Piper и русскую модель в Docker image, последующие используют кеш слоёв. Для синтеза облачные API не используются.
Локальный фронт: `npm ci`, `npm run build`, затем `npm run dev:web -- --host 127.0.0.1` (или `npm run dev --workspace=@factory/web -- --host 127.0.0.1`). Запущенный Vite подхватывает исходники через HMR. API и `/media` проксируются через туннель `127.0.0.1:18080`.

Превью Coverr и стоп-кадры кешируются в серверном volume `media/previews`. Файлы отдаёт API с Range-поддержкой. Недоступный источник показывает ошибку в карточке. Нельзя гарантировать наличие точного видео для любого имени или события в стоковой библиотеке.

Piper: https://github.com/OHF-Voice/piper1-gpl ; голос: https://huggingface.co/rhasspy/piper-voices/tree/main/ru/ru_RU/irina/medium . Лицензии движка и модели находятся у их авторов.
