# News Video Factory

Локальная панель остаётся на Mac, серверная часть запускается на Windows VPS в Docker.
Проекты, исходники, библиотека футажей и готовые ролики хранятся в Docker volumes
на сервере: панель можно закрыть и позже продолжить с того же проекта.

## Локально: панель

```bash
npm install
npm run dev:web
```

Перед запуском добавь в `apps/web/.env.local` адрес backend:

```env
VITE_API_URL=http://SERVER_TAILSCALE_IP:8080
```

## На сервере: backend

```powershell
Copy-Item .env.example .env
# В .env задай новый POSTGRES_PASSWORD
docker compose -f docker-compose.server.yml up -d --build
```

Проверка после запуска:

```powershell
Invoke-RestMethod http://localhost:8080/health
```

Не публикуй порты Postgres и Redis наружу. Для внешнего доступа к API используй Tailscale или обратный прокси с HTTPS.

## Библиотека и автомонтаж

В разделе «Библиотека футажей» можно один раз загрузить вертикальные или
горизонтальные видео и изображения и указать теги: например, `госдума,
заседание, документы`. При рендере сервис выделяет ключевые слова из текста
новости, берёт совпавшие футажи и равномерно раскладывает их по длине озвучки.
Можно выбрать конкретные элементы библиотеки или добавить файлы только в один
проект. Изображения используются как статичные кадры с озвучкой и субтитрами.

Автопоиск в сети включается после добавления `PEXELS_API_KEY` или
`PIXABAY_API_KEY` в серверный `.env`: worker сам ищет фото и видео для сцен,
скачивает выбранные файлы в серверный volume и сохраняет ссылку на источник и
автора в проекте. Pexels и Pixabay требуют указывать источник при показе
результатов; не используй их API для массового скачивания. `OLLAMA_MODEL`
необязателен: если локальная Ollama-модель задана, она превращает новость в
более точные визуальные запросы; без неё работает встроенное разбиение по
предложениям.

## Обновление сервера через Git

После того как репозиторий будет опубликован, на Windows сервере достаточно
один раз клонировать его в `C:\\Users\\aleck\\news-video-factory`. Дальше
обновление выполняется на сервере, без копирования архивов с Mac:

```powershell
powershell -ExecutionPolicy Bypass -File .\\infra\\deploy.ps1
```

Скрипт делает `git pull --ff-only` и пересобирает только сервисы приложения.

## Очередь рендера

Worker проходит стадии `storyboard → footage-selection → voiceover → captions → render`.
Текущий локальный голос — `espeak-ng`; сборка — FFmpeg. Позже его можно
заменить на Silero или XTTS, не меняя панель и очередь.
