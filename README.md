# Автомонтаж новостей

Тестовый self-hosted сервис: вставьте текст новости или ссылку на статью, проверьте
предложенные локальной моделью темы, выберите найденные кадры и соберите вертикальный
ролик с озвучкой и субтитрами. Панель запускается на компьютере редактора, а проекты,
медиа и рендер хранятся на Windows-сервере в Docker volumes.

Подробное подключение рабочего компьютера, серверный запуск и постоянный туннель:
[docs/REMOTE_SETUP.md](docs/REMOTE_SETUP.md).

## Локально: панель

```bash
npm install
npm run dev:web
```

Панель обращается к API через локальный SSH-туннель на `127.0.0.1:18080`.
Vite уже проксирует `/api`, `/health` и `/media` на этот адрес, поэтому
`VITE_API_URL` в разработке не нужен.

## На сервере: backend

```powershell
Copy-Item .env.example .env
# В .env задай новый POSTGRES_PASSWORD
docker compose -f docker-compose.server.yml up -d --build
```

Проверка после запуска:

```powershell
Invoke-RestMethod http://localhost:8080/health
```

Не публикуй порты Postgres и Redis наружу. Для внешнего доступа к API используй Tailscale или обратный прокси с HTTPS.

## Поиск кадров и автомонтаж

В разделе «Библиотека футажей» можно один раз загрузить вертикальные или
горизонтальные видео и изображения и указать теги: например, `госдума,
заседание, документы`. При рендере сервис выделяет ключевые слова из текста
новости, берёт совпавшие футажи и равномерно раскладывает их по длине озвучки.
Можно выбрать конкретные элементы библиотеки или добавить файлы только в один
проект. Изображения используются как статичные кадры с озвучкой и субтитрами.

После вставки текста локальная Ollama-модель выделяет 6–10 разных визуальных
тем и формирует английские запросы. Их можно исправлять, удалять и добавлять
перед поиском. Результаты из Coverr и Яндекс.Картинок показываются отдельно
для фото и видео, с указанием источника, предпросмотром, устранением дублей и
пагинацией. Выбранные материалы кешируются в проекте на сервере.

Для работы ИИ на сервере контейнер `ollama` должен один раз скачать модель:

```powershell
docker compose -f docker-compose.server.yml exec -T ollama ollama pull qwen2.5:3b
```

Если Ollama временно недоступна, в интерфейсе появится понятная ошибка; темы
можно добавить вручную. Не добавляйте API-ключи в Git: они хранятся только в
серверном `.env`.

## Обновление сервера через Git

После первого клонирования на Windows в `C:\\Users\\aleck\\news-video-factory`
обновление выполняется на самом сервере, без копирования архивов с Mac:

```powershell
powershell -ExecutionPolicy Bypass -File .\\infra\\deploy.ps1
```

Скрипт делает `git pull --ff-only` и пересобирает только сервисы приложения.

## Очередь рендера

Worker проходит стадии `storyboard → footage-selection → voiceover → captions → render`.
Текущий локальный голос — `espeak-ng`; сборка — FFmpeg. Позже его можно
заменить на Silero или XTTS, не меняя панель и очередь.
